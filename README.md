# Inkora

Inkora is a responsive blog website built using **HTML, CSS, and JavaScript**. It is inspired by modern editorial/blog websites and is being developed as a JavaScript practice project.

The project includes a clean homepage, featured articles, responsive blog cards, categories, tags, search functionality, and individual blog pages.

## Features

* Responsive homepage
* Featured blog posts
* Latest blog posts
* Responsive blog cards
* Categories and tags
* Individual blog detail pages
* Responsive navigation bar
* Responsive footer
* Search functionality
* Load More / pagination
* Mobile, tablet and desktop compatibility

### Bonus Features

* Dark mode
* Comment section
* Social sharing buttons
* Related article suggestions

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Responsive Web Design
* LocalStorage
